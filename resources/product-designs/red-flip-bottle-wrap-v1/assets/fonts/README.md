# Bottle wrap fonts

The font binaries in this directory originate from the official
[`google/fonts`](https://github.com/google/fonts) repository.

- `Anton-Regular.ttf`: Anton Regular, weight 400.
- `Allura-Regular.ttf`: Allura Regular, weight 400.
- `Fredoka-SemiBold.ttf`: static weight-600 instance of the official Fredoka variable font.
- `BodoniModa_18pt-Regular.ttf`: static `opsz=18`, weight-400 instance of the official Bodoni Moda variable font.

Each family is distributed under the SIL Open Font License 1.1. Its
corresponding unmodified license is stored as `OFL-<family>.txt`.
